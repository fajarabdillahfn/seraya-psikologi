WhatsApp manual payment (2026-09-01)

Business decision: MVP launch menggunakan WhatsApp manual payment (PDF + text invoice, Admin verifikasi). Midtrans Snap deferred ke post-MVP. Detail di ADR 0097.
  • Klien booking → invoice PDF + text generated → kirim via WhatsApp manual ke Admin
  • Klien transfer manual + kirim bukti → Admin verifikasi di /admin/payments
  • Admin mark-as-paid → Booking.state = 'confirmed'
  • Tidak ada payment gateway integration di MVP
